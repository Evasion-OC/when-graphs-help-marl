# JAIR submission guide

Target venue: **Journal of Artificial Intelligence Research (JAIR)** — Diamond Open
Access, **no submission fee, no APC** ([jair.org](https://www.jair.org)). Chosen after a
TMLR desk-reject of the earlier (pure-negative) version; JAIR rewards rigorous empirical
work without a novelty gate, MARL is explicitly in scope, and it mandates a
reproducibility checklist that this project's pre-registration + multi-seed + public code
satisfy directly.

## Build

The JAIR manuscript is **`paper/main_jair.tex`** (the TMLR build, `paper/main.tex`, is
kept as a fallback). JAIR requires the Volume-83+ ACM-based style (`jair.cls` wrapping
`acmart`) with **biblatex + biber** (not bibtex). All style files are committed in
`paper/` so the build is self-contained.

```bash
cd paper
pdflatex main_jair.tex
biber    main_jair         # NOT bibtex
pdflatex main_jair.tex
pdflatex main_jair.tex
```

Current state: compiles clean (32 pp, 0 errors, 0 undefined refs, all 34 references
resolved). Content parity vs the reviewed manuscript verified: every section, table
(16), figure (8), algorithm, and headline number preserved.

`main_jair.tex` is generated by `_assemble_jair.py` from `main.tex` (front matter swapped
to acmart, bibliography to biblatex, single-blind de-anonymization, JAIR reproducibility
checklist appended). Edit `main_jair.tex` directly from here on — the assembly script was
a one-time port.

## BEFORE you submit — author identity (single-blind; required)

JAIR is **single-blind**: it cannot be submitted as "Anonymous." Replace the placeholders
in the `\author` block of `main_jair.tex` (search `PLACEHOLDER`) with:

- Full author name(s) — currently only `Kasra Ghanavati` (from the repo LICENSE) is filled.
- Affiliation(s): institution, city, country.
- Email(s) and (recommended) ORCID(s).
- Update `\renewcommand{\shortauthors}{...}` if there is more than one author.

## Submission form metadata (suggested)

- **Primary area:** Reinforcement learning / Multi-agent systems. Do **not** set
  "graph neural networks" as primary — a pure graph-representation editor may misread the
  deliberately-minimal GCN as the contribution rather than a control.
- **Article type:** Research article (computational-experiments + light propositions).
- Lead the abstract with the **positive** structural-coordination result (d≈5, replicated),
  since "negative result" is not named in JAIR's scope and the abstract advertises the paper.

## Reproducibility checklist (mandatory — omission = desk reject)

Filled in at the end of `main_jair.tex` (`\section{Reproducibility Checklist for JAIR}`).
Code + raw data are the public MIT-licensed repo
(`https://github.com/Evasion-OC/when-graphs-help-marl`). Confirm the repo is **public**
before submission (JAIR is single-blind, so a public repo is fine and expected).

## Optional polish (non-blocking)

- **Abstract math:** JAIR discourages heavy math in the abstract (it is also rendered in
  HTML). The current abstract uses `$N{=}4$`, `$d\approx5$`, `$+5.4$`. Consider converting
  to words. Non-fatal.
- **Figure `\Description{}`:** acmart requests an accessibility description per figure.
  Currently absent (warnings only, not an error).

## Expectations

~13% raw acceptance / ~58% of non-desk-rejected; ~3 months to first decision; ~70%
acceptance on revise-and-resubmit. (Source: jair.org/transparent-publishing.)
